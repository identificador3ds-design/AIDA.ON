B2B API Integration

AIDA Developer Portal

Guia completo para conectar seu sistema à inteligência artificial de detecção de fraudes da AIDA.

1 Autenticação

A API da AIDA utiliza o padrão Bearer Token. A chave que fornecemos a você deve ser enviada no cabeçalho Authorization de cada requisição feita ao nosso servidor.

⚠️ Segurança: Nunca exponha essa chave no front-end (como no JavaScript do navegador) do seu site. Todas as chamadas para a nossa API devem partir do seu servidor backend (Node.js, Python, PHP, Java, etc).

HTTP Headers 
Authorization: Bearer SUA_CHAVE_DE_API_AQUI

2 Realizando uma Análise

Para analisar uma imagem, envie uma requisição POST com formato multipart/form-data. O limite máximo de tamanho de arquivo é de 15MB.

POST https://aidaon-aida-borda-api.hf.space/v1/analyze/image

Parâmetros da Requisição (Form Data)

Campo Tipo Obrigatório Descrição
image File Sim O arquivo da imagem (JPEG, PNG, WEBP, etc).
evidence boolean Não Defina como false se não precisar do mapa de calor (reduz processamento). Padrão é true.

3 Exemplos de Código (Backend)

Copie o trecho abaixo de acordo com a linguagem do seu servidor para realizar a integração rapidamente.

Node.js (Axios) 
const axios = require('axios');
const FormData = require('form-data');
const fs = require('fs');

async function analisarDocumento(caminhoImagem) {
    const form = new FormData();
    form.append('image', fs.createReadStream(caminhoImagem));
    form.append('evidence', 'true');

    try {
        const response = await axios.post(
            'https://aidaon-aida-borda-api.hf.space/v1/analyze/image', 
            form, 
            {
                headers: {
                    ...form.getHeaders(),
                    'Authorization': 'Bearer aida_WGzt7D00yExZ4mI-UZxyF...' // Use variável de ambiente!
                }
            }
        );
        console.log('Resultado:', response.data);
    } catch (error) {
        console.error('Erro na API:', error.response ? error.response.data : error.message);
    }
}
Python (Requests) 
import requests

def analisar_documento(caminho_imagem):
    url = "https://aidaon-aida-borda-api.hf.space/v1/analyze/image"
    headers = {
        "Authorization": "Bearer aida_WGzt7D00yExZ4mI-UZxyF..." # Use var de ambiente!
    }
    
    with open(caminho_imagem, "rb") as f:
        files = {"image": f}
        data = {"evidence": "true"}
        
        response = requests.post(url, headers=headers, files=files, data=data)
        
    if response.status_code == 200:
        print("Resultado:", response.json())
    else:
        print("Erro:", response.status_code, response.json())

4 Processando a Resposta

Se a requisição for bem-sucedida (Status 200 OK), você receberá um JSON detalhado com o veredito da IA.

JSON Response (Exemplo de Sucesso) 
{
  "analysis_id": "hash_unico_da_analise",
  "result": "IA/MANIPULADA", // "REAL" | "IA/MANIPULADA" | "INCONCLUSIVO"
  "ai_probability": 0.985, // Confiança da IA (0 a 1)
  "confidence": "ALTA", // "ALTA" | "MEDIA" | "BAIXA"
  "details": {
    "models": [
      { "name": "forense", "ai_probability": 0.99, "status": "ok" },
      { "name": "clip", "ai_probability": 0.98, "status": "ok" }
    ]
  },
  "metadata": {
    "duration_seconds": 2.1
  }
}

Lógica de Negócios Sugerida

No seu backend, você pode criar uma regra simples baseada no campo result:

  • REAL: Aprove o fluxo do usuário normalmente.
  • IA/MANIPULADA: Bloqueie a transação e encaminhe para revisão humana ou recuse.
  • INCONCLUSIVO: Peça ao usuário para enviar uma foto com melhor iluminação.

5 Tratamento de Erros e Limites

Sua integração deve estar preparada para lidar com os seguintes códigos HTTP da API:

Status Código Interno Significado
400 invalid_image Arquivo vazio, corrompido ou formato não suportado.
401 invalid_key Chave de API ausente, inválida ou revogada.
413 payload_too_large O arquivo ultrapassa o limite de 15MB.
429 rate_limited Sua empresa excedeu o limite do plano contratado nesta hora. Tente novamente mais tarde. Leia o header Retry-After.
503 busy Servidores da AIDA sob carga máxima. Tente de novo em alguns segundos.
