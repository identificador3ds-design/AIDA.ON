Como se conectam

Um só núcleo, quatro portas de entrada.

  1. 1
    AIDA Core

    Três métodos independentes (rede neural CLIP, medidas forenses e RIGID) combinados por uma fusão calibrada.

  2. 2
    Image e Video

    Usam o Core para fotos e, quadro a quadro, para vídeos, somando movimento e áudio.

  3. 3
    Forensics

    Reabre qualquer análise e mostra o material que sustentou o resultado.

  4. 4
    API

    Entrega o mesmo resultado a outros sistemas, sem uma segunda lógica de decisão.

As imagens dos cards são demonstrações. O resultado do AIDA é um indício técnico, nunca uma prova sobre a origem de um conteúdo.
