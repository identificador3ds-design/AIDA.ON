AIDA API

Leve a análise do AIDA para dentro do seu sistema. Seu programa envia uma imagem por HTTP e recebe, em JSON, o mesmo resultado que a plataforma mostra: o veredito em três estados, a probabilidade, os scores de cada método, as evidências visuais e a ressalva.

Em linguagem simples

Uma porta para outros programas usarem o AIDA.

Na plataforma, uma pessoa envia a imagem pela tela. Com a API, quem envia é outro sistema — o site de uma redação, uma ferramenta de moderação, um projeto de pesquisa — sem ninguém precisar abrir o AIDA. A análise é exatamente a mesma: não existe um detector diferente para a API.

Envia

Uma imagem

JPG, PNG, WEBP, BMP, HEIC ou AVIF, com até 15 MB, junto com a chave de acesso da sua aplicação.

Recebe

Um resultado completo

Veredito, probabilidade, confiança, notas de cada método, qualidade da imagem, limitações e links para os mapas de evidência.

Para quem

Quem verifica imagens em volume

Redações e agências de checagem, plataformas de denúncia e moderação, pesquisa acadêmica e ensino de letramento digital.

Primeira chamada

Três passos até o primeiro resultado.

Passo 01

Peça uma chave

A chave identifica a sua aplicação e define a cota de uso. Ela é emitida pela equipe do AIDA.

Passo 02

Envie a imagem

Um POST em formulário (multipart) com o arquivo no campo image.

Passo 03

Leia o resultado

Trate os três estados e mostre a probabilidade de exibição junto com a ressalva.

Requisição curl 
curl -X POST https://<host-da-api>/v1/analyze/image \
  -H "Authorization: Bearer <sua-chave>" \
  -F "image=@foto.jpg" \
  -F "evidence=true"

# evidence=true pede também os mapas visuais

Boas práticas

O que toda integração precisa respeitar.

Estados

Trate os três resultados

result vale REAL, IA/MANIPULADA ou INCONCLUSIVO. Um if/else binário rotularia como IA justamente o que o sistema declarou indeterminado.

Número

Mostre ai_probability

É a escala de exibição, com corte em 50%. A probabilidade calibrada, em calibration, usa outro ponto de corte e confunde quem lê.

Ressalva

Exiba o disclaimer

O resultado é um indício técnico, não uma prova de autoria ou de manipulação. A ressalva deve acompanhar o resultado em qualquer interface.

Limites

Cota e erros

60 análises por hora por chave (padrão). 401 chave inválida, 413 arquivo grande demais, 429 cota esgotada — respeite o cabeçalho Retry-After.

Como funciona por dentro

Uma camada fina sobre o AIDA Core.

A API não tem lógica de detecção própria. Ela recebe a requisição, confere a chave, valida o arquivo, aplica a cota, entrega a imagem ao AIDA Core e devolve a resposta no contrato versionado. Assim, a decisão é sempre a mesma que a plataforma mostra.

Camada 01

Borda HTTP

Autenticação por chave (Bearer), limite de uso por janela, validação de formato e tamanho.

Camada 02

Orquestração

Fila para requisições simultâneas, cache por conteúdo e registro de cada chamada.

Camada 03

AIDA Core

O mesmo pipeline do AIDA Image: CLIP, módulo forense, RIGID, fusão calibrada e proveniência.

Camada 04

Contrato /v1

Campos estáveis em inglês; mudanças que quebram compatibilidade só em uma nova versão.
